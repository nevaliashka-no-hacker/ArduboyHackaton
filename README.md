# ArduboyHackaton
# Cloud Jumper
В этой игре вам предстоит прыгать по облакам и защищаться от пролетающих мимо птиц.

# Правила
На главном экране (menu):
- нажмите A для старта.

В самой игре:
- A - стрельба вверх по птичкам (они дают дополнительные очки)
- B - запуск защитного шара вокруг персонажа на 1-3 сек (за игру 3 штуки)
- Стрелки - направление движения персонажа (вниз - ускорение падения, вправо - движение вправо, влево - движение влево, вверх - двойной прыжок)

Персонаж не попал на облако и полетел вниз - окончание игры.

# Особенности
В игре ведется подсчет очков. Чем выше пропрыгает по облакам персонаж - тем больше у него очков. Также можно получить дополнительные очки за попадание по птице.
